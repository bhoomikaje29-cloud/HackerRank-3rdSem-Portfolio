## Optimization Techniques Learned

Through these problems, I learned how to choose efficient algorithms and data structures instead of using unnecessary nested loops.

- **Diagonal Difference:** Accessed only the required diagonal elements instead of processing unnecessary elements.
- **Dynamic Array:** Used sequence-based storage and efficient query processing.
- **Time Conversion:** Used simple string operations to solve the problem in constant time.
- **Compare the Triplets:** Used direct comparison and counting.
- **Sparse Arrays:** Used a HashMap to store string frequencies, allowing queries to be answered efficiently without repeatedly scanning the complete list.

Overall, these problems improved my understanding of time and space complexity and helped me select efficient approaches based on problem constraints.
